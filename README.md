# [NOME] · il sito delle app

Il sito che presenta le quattro app di Donato Cipriano per la scuola: **Leggo e Scrivo**, **Matematica Amica**, **Geografia Amica** e **Solfeggio e Teoria**.

Solo HTML e CSS, senza JavaScript e senza risorse esterne: niente cookie, niente statistiche, niente caratteri da altri siti.

## Che cosa c'è

| File | Che cos'è |
|---|---|
| `index.html` | la pagina principale |
| `privacy.html` | la privacy del sito, con i link al supporto e alla privacy di ogni app |
| `style.css` | lo stile (modello "Aula luminosa", tema chiaro) |
| `font/` | Nunito, Atkinson Hyperlegible e Playwrite IT Trad, con le loro licenze SIL Open Font License |
| `immagini/app/` | le icone delle app, a 300 e 450 punti |
| `immagini/icone/` | le icone originali, 1024 × 1024 |
| `immagini/condivisione.png` | l'immagine che compare quando si condivide il link (1200 × 630) |
| `immagini/favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | l'icona del sito |

## I caratteri

- **Nunito** (800, 900): dal progetto ufficiale su GitHub (`google/fonts`, cartella `ofl/nunito`), solo l'alfabeto latino. Licenza: `font/OFL-Nunito.txt`.
- **Atkinson Hyperlegible** (400, 700): licenza `font/OFL-AtkinsonHyperlegible.txt`.
- **Playwrite IT Trad** (400): licenza `font/OFL-PlaywriteITTrad.txt`.
